Recorded on each scan

  • The date and time
  • The kind of device: phone, tablet or computer
  • The operating system and browser
  • An anonymous code, so repeat scans by the same person count once

Never recorded

  • IP addresses. They are turned into the anonymous code and then thrown away.
  • Names, emails or locations of the people who scan
  • Cookies. Scanning a code puts nothing on the scanner's phone.
  • Your password in readable form. It is stored hashed, so nobody can read it.
